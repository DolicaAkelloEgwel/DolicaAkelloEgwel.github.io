## Requirements

- uv
- ffmpeg

## Installation

1. Install the required software. The steps to do this will depend on what platform you're using.
2. Clone the [repository](https://github.com/DolicaAkelloEgwel/Face-Morphing).
3. In the project folder, enter the following command in the terminal or shell:

```
uv sync
```
