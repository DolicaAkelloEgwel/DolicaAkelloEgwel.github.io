## Usage

### Choosing a Colour to Track

The code can run with hard-coded pre-defined colours, or by being set with a colour-picker.

#### Colour Picker

To use the colour-picker, enter the following command in the project root directory:

```
uv run colour_picker.py
```

This will then open a window with your webcam. Hold the object you would like to track in front of your camera and then click on it with your mouse. This will then try to determine the appropriate HSV values for tracking that object and record them in a config file. You can do this multiple times, but then this will cause the existing config file to be overwitten. Press Q to exit the code when you are done.

Be aware that lighting level, shininess of the object, etc may mean that the same set of values will not necessarily work under all conditions. If you intend to use this for an installation, it would be best to run the colour-picker code in the environment in which your installation will be setup if possible.

#### Predefined Colours

There are some colours already hard-coded into the program. These are:

- blue
- yellow
- red
- black
- white
- green
- purple
- orange

### Tracking an Object

For detecting a coloured object in a recorded video:
```
uv run main.py --video YOUR_VIDEO_FILE.mp4
```

For live detection via webcam:
```
uv run main.py
```

#### Command Line Arguments

##### `-tl, --trace-length`

Controls the lenght of the red line that shows where the tracked object has been previously. Defaults to 64.

##### `-ht, --hide-trace`

Hides the trace line.

##### `-hc, --hide-circle`

Hides the circle drawn around the object.

##### `-c, --colour`

Chooses a predefined colour to track. Giving an argument for this causes the config file generated by the colour picker to be ignored.

## Limitations

1. It can't track multiple objects
2. No other object of the same colour should be there, otherwise we won't be able to track successfully.
